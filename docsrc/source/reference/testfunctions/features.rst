Shared Features and Known Gaps
==============================

Features that work the same way across testfunctions: files inside archives, globs, regex and
time placeholders, ordered comparisons, counts, key paths. Each function's page lists the ones it
supports and the ones it does not. ``adare test feature <id>`` prints the same text, and
``adare test search --feature <id>`` lists the functions that support one.
